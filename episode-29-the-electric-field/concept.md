# El campo eléctrico · figura interactiva

Una sonda sostenida recorre un tablero entre placas; una segunda sonda permanece dentro de una jaula conductora. El movimiento prescribe la posición, mientras el voltímetro mide el potencial y el modelo calcula la fuerza sobre una carga de prueba. Se comparan dos montajes ideales independientes.

Piezas: base nivelable, placa de inscripción, tablero aislante, dos electrodos de espesor real, seis trazas grabadas, carro con vástago y esfera, jaula de tres anillos octogonales rectangulares con juntas esféricas y barrotes, sensor interior sostenido, voltímetro de aguja y mando moleteado. Las juntas tangentes permiten auditar cada pieza real. Los barrotes simbolizan una envolvente conductora ideal cerrada; no se simulan fugas entre sus aberturas.
